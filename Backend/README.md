# Coffee Shop Backend API

## Technologies Used

- Node.js
- Express.js
- CORS
- Nodemon

## REST APIs

### Register

POST /api/auth/register

Registers a new user.

### Login

POST /api/auth/login

Authenticates an existing user.

### Contact

POST /api/contact

Accepts contact form details.

## Testing

All APIs were tested successfully using Postman.
